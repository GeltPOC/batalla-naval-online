# Batalla Naval Online

Juego multijugador de Batalla Naval en tiempo real con Socket.io y Next.js.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
npm start
```

## Cómo jugar

1. Introduce tu nombre.
2. Crea una sala (obtienes un código de 6 caracteres) o únete a una existente.
3. Coloca tus 5 barcos en el tablero (puedes rotar con el botón Rotar).
4. Cuando ambos jugadores estén listos, comienza la batalla.
5. Haz clic en el tablero enemigo para disparar. 🔴 = impacto, 🔵 = agua.
6. Los impactos permiten volver a disparar. El primero en hundir todos los barcos gana.
